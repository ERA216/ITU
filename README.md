# Чистый счёт

Защита честных клиентов банка от статуса дроппера: перехват схемы «ошибочный перевод»,
безопасный возврат отправителю и разбор блокировок. Проект для ITU Hackathon-2026, кейс Банка ЦентрКредит.

## Запуск

```
pip install -r requirements.txt
python -m app.seed            # создаёт data.db с синтетическими данными и печатает качество движка
uvicorn app.main:app --reload # экран клиента на http://127.0.0.1:8000, документация API на /docs
python -m pytest -q           # тесты
```

## Что уже есть

- `app/db.py`: схема базы (клиенты, переводы, случаи, документы).
- `app/engine.py`: движок перехвата. Каждый признак даёт баллы и текст причины; перевод останавливается от 75 баллов.
- `app/seed.py`: генератор данных. 300 клиентов, 90 дней истории, схема с дропперами и похожие на неё честные ситуации.
- `app/main.py`: API. Создание перевода, безопасный возврат, «настаиваю на переводе», список случаев, апелляция.
- `app/static/index.html`: экран клиента. Перевод, окно перехвата, а для заблокированного клиента причина блокировки и подача документов.

## Демо-персонажи (создаются при seed)

| id | Кто |
| --- | --- |
| 1001 | Айдана, студентка. 20 минут назад получила 150 000 ₸ от незнакомца |
| 1002 | Незнакомый отправитель (жертва) |
| 1003 | Карта «для возврата», счёту 6 дней (дроппер) |
| 1004 | Мама, знакомый получатель |
| 1005 | Данияр, продавец. Два дня назад переслал чужие деньги и заблокирован: на нём показывается апелляция |
| 1006 | Покупатель, от которого Данияр получил деньги |

Перевод 1001 → 1003 на 150 000 останавливается; 1001 → 1004 проходит.

## Известные ограничения

- Данные синтетические, цифры качества относятся только к ним.
- Движок пропускает дробление суммы на части и пересылку позже 72 часов.
